## Выполненные задания

### Средней сложности

1. **№6 — Калькулятор**

Реализован калькулятор для выполнения основных арифметических операций: сложения, вычитания, умножения и деления.  
Также предусмотрена проверка деления на ноль.

Файл: `calculator.py`

2. **№8 — Перевернуть строку**

Реализована функция, которая принимает строку и возвращает её в обратном порядке.

Файл: `reverse_string.py`

3. **№2 — Сумма всех нечётных чисел до N**

Реализована программа для подсчёта суммы всех нечётных чисел от 1 до введённого пользователем числа N.

Файл: `odd_sum.py`

### Повышенной сложности

4. **№4 — Построить график y = x^2 с matplotlib**

С помощью библиотеки matplotlib построен график функции y = x^2.

Файл: `graph.py`

5. **№10 — Сериализация данных в JSON**

Реализовано сохранение данных в JSON-файл и последующее чтение сохранённых данных.

Файлы: `json_serialization.py`, `data.json`

## Структура проекта

- `calculator.py` — калькулятор
- `reverse_string.py` — переворот строки
- `odd_sum.py` — сумма нечётных чисел до N
- `graph.py` — построение графика y = x^2
- `json_serialization.py` — сериализация и десериализация JSON
- `data.json` — файл с сериализованными данными
- `requirements.txt` — зависимости проекта
- `.gitignore` — исключения Git

## Установка зависимостей

Для установки необходимых библиотек выполнить:

```bash
py -m pip install -r requirements.txt
```
